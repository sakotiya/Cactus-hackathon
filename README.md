# ExamGuard React Frontend

A ChatGPT-style interface for the ExamGuard AI Study Coach.

## Features

- 💬 Chat-style conversation interface
- 📎 PDF upload support
- 🎤 Voice recording with transcription
- ✨ Modern dark theme (ChatGPT-inspired)
- 📱 Mobile-responsive design

## Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The frontend runs at `http://localhost:3000` and proxies API requests to the backend at `http://localhost:8000`.

## Build for Production

```bash
npm run build
```

Output will be in the `dist/` folder.
